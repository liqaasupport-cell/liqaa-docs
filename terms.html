  • التحرش والتنمر الإلكتروني: يُمنع توجيه الإهانات الشخصية، أو المضايقات المستمرة، أو المطاردة الإلكترونية، أو التشهير بأي مستخدم آخر داخل الغرف الصوتية أو المحادثات الخاصة.
  • المحتوى الإباحي والفاضح: يُحظر بث أو نشر أي محتوى يتضمن تعرياً، أو إيحاءات جنسية صريحة، أو مواد إباحية، أو محتوى لا يتناسب مع الذوق العام الآمن للمنصة.
  • انتحال الشخصية والتزييف: يُحظر التظاهر بأنك شخص آخر، أو ادعاء تمثيل شركة أو جهة رسمية أو إدارة التطبيق دون إذن موثق، وكذلك يمنع تزوير هويات البوتات أو الحسابات الموثقة.
